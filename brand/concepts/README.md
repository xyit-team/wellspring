## 推荐的元素

**盘起来的弹簧。** wellspring 现在读作「泉」；这个标记把它读成另一个 spring——弹簧：一圈一圈把力存起来，再放出去。平台也是这件事：插件、模型、会话是绕上去的圈，用户按下去的那一刻，它才把力交出来。

名字可以不用换：wellspring 里本来就藏着这个双关。如果一定要换，**Mainspring** 是同一条思路的直说版。

另外三个方向（aqueduct / manifold / estuary）留在概念板里，各自还差一口气，等选定方向后再收。
